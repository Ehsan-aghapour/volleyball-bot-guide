گرفتن فایل‌ها و به‌روزرسانی

دو چیز داری و کارشان فرق می‌کند:

۱ — سایت راهنما

همین صفحه‌ها. در مرورگر بازشان می‌کنی و همیشه آخرین نسخه‌اند. هیچ کاری برای به‌روز کردنشان لازم نیست؛ فقط صفحه را تازه کن.

۲ — پوشه‌ی فایل‌ها

فایل‌هایی که باید روی لپ‌تاپت باشند. این‌ها را یک‌بار می‌گیری، و هر وقت احسان گفت به‌روز شده، با یک دستور نسخه‌ی جدید را می‌گیری.

الان لازم است

۱ — نصب گیت

گیت ابزاری است که با آن فایل‌ها را می‌گیری و به‌روز می‌کنی. از این آدرس نصبش کن:

https://git-scm.com/downloads

در تمام مراحل نصب فقط دکمه‌ی بعدی را بزن. برای اطمینان از نصب، در ترمینال بزن:

git --version

اگر یک شماره‌ی نسخه نشان داد، نصب شده.

۲ — گرفتن فایل‌ها

ترمینال را باز کن و این دو دستور را یکی‌یکی بزن:

cd Desktop
git clone https://github.com/Ehsan-aghapour/volleyball-bot-guide.git

حالا روی دسکتاپ یک پوشه‌ی تازه ساخته شده به این اسم: 

volleyball-bot-guide

اگر دستور جواب نداد یا وسط کار قطع شد، اول وی‌پی‌ان را چک کن و دوباره بزن.

۳ — کپی کردن در پوشه‌ی پروژه

داخل پوشه‌ای که تازه گرفتی، یک پوشه هست به اسم:

bot-starter

محتویات آن را در پوشه‌ی پروژه‌ات کپی کن — نه خود پوشه را، بلکه فایل‌های داخلش. اسم پوشه‌ی پروژه‌ات این است: 

volleyball-bot

هر وقت احسان گفت فایل‌ها به‌روز شده

ترمینال را باز کن و این دو دستور را بزن:

cd Desktop/volleyball-bot-guide
git pull

تمام. اگر فایلی عوض شده باشد، حالا نسخه‌ی جدیدش را داری.

قانون این پوشه: هیچ‌وقت فایل‌های داخل volleyball-bot-guide را تغییر نده. این پوشه فقط برای گرفتن فایل است، نه برای کار کردن. کار تو در پوشه‌ی پروژه انجام می‌شود.

اگر دستور بالا خطا داد، این دو تا را پشت سر هم بزن:

git reset --hard
git pull

اگر باز هم خطا داد، به احسان بگو و برو سراغ کار بعدی.

دو پوشه‌ای که داری

پوشه‌ی پروژه — اینجا کار می‌کنی

هر چیزی که می‌سازی اینجاست. کلود اینجا کد می‌نویسد.

volleyball-bot
پوشه‌ی فایل‌ها — فقط می‌گیری

هیچ‌وقت دستش نمی‌زنی. فقط گاهی نسخه‌ی جدید می‌گیری.

volleyball-bot-guide

حساب گیت‌هاب — برای بعد

برای گرفتن فایل‌ها حساب لازم نیست. ولی چند هفته‌ی دیگر که کدت را جایی امن نگه می‌داریم، لازم می‌شود. اگر همین حالا می‌خواهی درستش کنی، سه دقیقه طول می‌کشد: 

https://github.com/signup

نام کاربری‌ای انتخاب کن که بعداً هم به کارت بیاید. این اسم کنار هر کدی که می‌نویسی دیده می‌شود.
